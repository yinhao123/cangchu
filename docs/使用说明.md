# 使用说明

> 本文档面向实际使用者（仓管员 + 管理员），**不假设你会命令行**。
> 界面元素一律用「左侧导航 → 页面名」的写法描述；括号里的 `/xxx` 是浏览器地址栏里的路径。

## 一、第一次使用（5 分钟）
1. 双击 `ScanableSelf.exe`。**不会弹出任何窗口**，这是正常的 —— 它在后台跑服务。
2. **先激活**：浏览器打开服务地址后会自动跳到「激活」页 → 复制页面上的**机器码**发给卖家 →
   把拿到的注册码粘进输入框 → 点〔激活〕。
   激活成功后重新打开地址就是登录页了；以后重启程序**不需要**再激活（授权与这台电脑绑定，换主板/换电脑要重新激活）。
3. 找访问地址：打开 `%LOCALAPPDATA%\ScanableSelf\` 目录（地址栏里贴 `%LOCALAPPDATA%\ScanableSelf` 回车即可），
   里面有个「访问地址」文本文件与一张**访问二维码**；同一局域网里的任意电脑用浏览器打开这个地址。
   → 也可以用「手机配对」页看到地址与二维码。
4. 初始账号 `admin` / 密码 `admin123` → **登录后必须立即改密码**（系统会强制，没改之前其他功能都用不了）。
5. 「左侧导航 → 系统设置 → 设备与配对」里改「设备名称」（手机列表里看到的名字）。
6. 「左侧导航 → 备份与恢复」→〔立即备份〕一次 → 确认列表里出现备份文件。
⚠️ 电脑要一直开着。Windows 首次运行会弹防火墙授权，**必须点「允许访问」**，否则别的设备打不开界面（手机也无法自动发现）。

## 二、仓管员：用手机扫码入库
1. 手机与电脑连**同一个 WiFi**。
2. 打开 APP → 一般 3 秒内出现「发现电脑：仓库电脑」→ 点连接 → 登录。
   没出现？→ 用手机扫「手机配对」页上的二维码 → 仍不行见第六章。
3. 首页点〔入库扫码〕→ 对准条码 → 听到「滴」+ 震动 → 确认商品名与当前库存 → 输入数量 → 提交。
4. 连续扫码：提交后条码框会自动清空并重新聚焦，直接扫下一件即可。
5. 出库同理，只是方向相反。**库存不够时系统会拒绝并告诉你缺几件**，不会自动少扣。

## 三、电脑端（浏览器）操作
- 扫码枪（USB 即插即用）：「出入库」页的条码框会自动聚焦，扫完回车即提交。
- 出入库：「侧边导航 → 出入库」，顶部切换 **入库 / 出库 / 盘点调整**（盘点仅管理员）。
  左边选仓库、扫码、填数量，右边大字显示**本次结果与当前结存**；连续扫描不打断（仓库与模式会保留）。
- 查账：「流水查询」（可按日期/类型/仓库/操作员/关键字筛，可导出 Excel 能打开的 CSV）、
  「库存现状」（可切「仅看预警 / 仅看异常」）、「汇总报表」。
- 打错了怎么办：在「流水查询」里找到那笔 →〔冲销〕并填写原因
  （系统会记一笔反向账，**不会删除原记录**，这样查账才看得懂）。

## 四、基础数据
- 「商品与条码」：名称、条码、分类、单位、成本价、售价、预警下限（库存低于它就进首页预警）。
  没有条码的商品可以留空 → 系统生成内码（`S` 开头）→ 到「标签打印」打出来贴上，之后就能扫码。
- 「仓库」：多仓库就建多个；**有库存的仓库不能停用**。
- 「客户 / 供应商」：出库选客户、入库选供应商，方便对账。
- 只有管理员能改这些基础数据；仓管员账号（operator）只能扫码出入库和查询。

## 五、打印条码标签
「标签打印」→ 搜索商品 → 勾选 → 设「每款张数」（1~50）→ 点〔打印〕。
打印预览里**只会出现标签网格**（搜索区与表格不会打出来）；标签纸尺寸在「系统设置 → 业务与提醒」里改。
若某款商品提示「标签过窄」，说明当前标签纸放不下这个条码，换大一号的纸。

## 六、别人打不开界面 / 手机连不上电脑（按顺序试）
1. 在**服务端那台电脑**上打开 `http://127.0.0.1:5000/` 能不能出登录页？
   - 能 → 服务正常，问题在网络（继续第 2 步）；不能 → 服务没起来，见第七章。
2. 地址里的**端口对不对**？端口可能不是 5000（被占用时会自动换到 5001~5010），**以「手机配对」页显示的为准**。
3. 「手机配对」页有没有提示「局域网自动发现已关闭」→ 是的话在「系统设置 → 网络与安全」里打开（需要再输一次你自己的密码）。
4. 防火墙：按「手机配对」页给出的命令放行，或 Windows 设置 → 防火墙 → 允许 ScanableSelf 通过专用网络。
5. 手机和电脑是不是同一个 WiFi？手机能上外网却打不开电脑 → 路由器开了「AP 隔离」，需要在路由器里关掉。
6. 都不行 → 手机上手动输入 `IP:端口`（端口看「手机配对」页）。长期建议：在路由器里给这台电脑绑定固定 IP。

## 七、断网了还能扫吗
**能。** 手机断网时扫码会先存到手机本地，屏幕左上角显示「N 条待同步」。网络恢复后自动上传，
每笔只入账一次（重复提交会被自动合并）。所以电脑临时关机、网络抖动都**不会丢扫码记录**。

## 八、管理员：备份与恢复（最重要）
- 系统每天 03:00 自动备份（需程序在运行）。首页出现**红色「备份已停止」**提示时要立刻处理。
- 手动备份：「备份与恢复」→〔立即备份〕。**做重要操作前都先备份一次。**
- 恢复到某天：「备份与恢复」选文件 → 输入你的密码 → 确认。恢复前系统会自动把**当前库**也备份一份（万一要回退）。
- 「库存一致性自检」发现不一致时可〔按流水重算〕：以流水为准修正库存表，重算前也会自动备份。
- ⚠️ 备份文件包含全部业务数据，请像保护账本一样保护它（不要放公共网盘）。
- ⚠️ 备份一定要**演练过一次恢复**，没试过的备份不算备份。
- 库存数字对不上：按 `docs/07-运维手册.md` 第 1.4 节处理（先查差异、再用〔冲销〕或〔盘点调整〕修正，**严禁手工改数据库**）。

## 九、常见小问题
| 现象 | 怎么办 |
|---|---|
| 双击 exe 没反应 | 看 `docs/07` 第 2 章；用 `ScanableSelf-debug.exe`（带控制台）看报错 |
| 浏览器打开一片白 | 服务端少了前端构建产物：页面会给出提示，按提示在 `desktop/web` 跑一次构建后再打包 |
| 页面只有文字没样式 / 排版乱 | 浏览器内核太旧，换 Chrome / Edge 打开（见第十二章） |
| 地址打不开、端口不是 5000 | 端口被占用时程序会自动换到 5001~5010，以「手机配对」页显示的为准 |
| 条码扫不出来 | 光线/距离；条码是否破损；确认商品已登记该条码；也可能标签纸太小导致条码过窄 |
| 提示「该商品已停用」 | 找管理员在「商品与条码」里恢复它 |
| 提示「库存不足」 | 是真的不够，不是系统错。确认实物或先补入库 |
| Excel 打开 CSV 乱码 | 用「数据 → 从文本/CSV」导入，选 UTF-8 |
| 首页显示负库存（红字） | 数据异常，按运维手册 1.4 排查 |
| 打开就跳「激活」页 | 本机还没激活或授权文件损坏：把页面上的机器码发给卖家换注册码（见第一章第 2 步） |
| 想改端口 / 关掉自动发现 | 「系统设置 → 网络与安全」，改完需要重启程序，且要再输一次你自己的密码 |
| 演示完想恢复干净环境 | 关程序 → 删掉 `demo-data` 目录 → 再双击 `启动演示模式.bat`（只影响演示数据，不动真实账本） |
| 开单时提示「单据功能已关闭」 | 「系统设置 → 业务与提醒」里把 WMS 单据总开关打开 |

## 十、单据模块（采购 / 入库 / 领用 / 借还 / 调拨）
> 单据只管「要收多少、收了多少」；**库存只在审批通过那一刻才动**，且整单要么全过、要么全不过。

- **采购订单**（左侧导航 → 单据 → 采购订单）：选供应商、加商品行、填数量与单价 → 提交 → 管理员在
  「审批待办」里通过 → 订单变「已审批」。
- **采购入库**（单据 → 采购入库）：引用已审批的订单 → 填实收数量 → 提交 → 管理员通过时**同步加库存**。
  收满的订单会自动变「已关闭」；超收会被拦下（提示可收数量），不会先把库存加上再报错。
- **领用 / 借还 / 调拨**（单据 → 领用 / 借还 / 调拨）：
  - 领用、借用：**减**库存；借用必须填「预计归还日期」；归还时再开一张「归还」单**加**回库存。
  - 退库：车间/门店把未用完的料退回，**加**库存。
  - 调拨：一次生成「出 + 入」两条流水（调出仓减、调入仓加），同一事务，不会只成功一半。
- 管理员可以在「审批待办」里一次看到三类待审批单据；驳回必须填原因。
- 已审批过账的单据**不能改明细、也不能删**：要更正就在「流水查询」里对那笔冲销（红字），再重开一张单。
- 不需要单据功能时，「系统设置 → 业务与提醒」里可关掉总开关：关闭后只是不能再开新单，历史单据与库存完全不变。

## 十一、给客户演示（演示数据）
> 演示数据放在**独立的数据目录**里，绝不碰真实账本。

1. 把交付包解压到一个可写目录（**不要放 C:\Program Files**）。
2. 双击 **`启动演示模式.bat`**（和 `ScanableSelf.exe` 同一个目录）。
   它会：用 `demo-data` 子目录当数据目录 → 首次自动灌入演示数据 → 3 秒后打开浏览器。
3. 演示账号：

   | 账号 | 口令 | 角色 | 能做什么 |
   |---|---|---|---|
   | `admin` | `admin123` | 管理员 | 全部功能（首次登录会要求改密，演示时改成 `Demo2026` 即可） |
   | `wh01` | `Demo2026` | 仓管员 | 出入库、查账；看不到管理员菜单 |

   口令可用环境变量改：`SCANABLE_DEMO_PASSWORD`（演示账号）、`SCANABLE_INIT_PASSWORD`（admin 初始口令）。
4. 演示数据里已经准备好的内容：
   - 14 个商品（5 个分类，条码可直接扫）、3 个顶级仓 + 2 个库位（两级树）；
   - 5 个往来单位（3 供应商 / 2 客户）；
   - 最近 30 天的出入库流水（约 140 条）、2 次盘点、1 笔已冲销的红字；
   - 若干**低于预警线**的商品（仪表盘与「库存现状 → 仅看预警」有内容）；
   - 10 张单据：采购订单（已审批 / 待审批 / 草稿）、采购入库（已过账 / 待提交）、
     领用（已过账）、借用（待审批）、调拨（已过账，含出+入两条流水）、退库、归还。
5. 想重新演示一遍：关掉程序 → 删掉 `demo-data` 目录 → 再双击 `启动演示模式.bat`。
   想给真实客户用：直接双击 `ScanableSelf.exe`（数据在 `%LOCALAPPDATA%\ScanableSelf\`，与演示数据完全分开）。
6. 备注：演示模式同样需要激活（激活信息记在本机，不受数据目录影响）。

## 十二、这套系统的边界（请知悉）
同一局域网内使用 · 电脑需常驻开机（建议设开机自启）· 访问端**不需要装任何软件**（浏览器打开即用）·
浏览器请用 **Chrome / Edge**（Win7 上最高可装 109 版），**不支持 IE**，旧内核的其他浏览器可能出现样式错乱 ·
单账套、无细粒度多角色权限 · 浏览器打印而非专业小票直连 ·
无云端同步（换电脑靠拷数据目录） · 局域网内明文 HTTP，**绝对不要把端口映射到公网** ·
同时写入的浏览器不要超过 3~5 个（再多可能出现「数据库忙」，稍等重试即可）。
