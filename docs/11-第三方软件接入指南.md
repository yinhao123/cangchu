| 联调开关 | `VERIFY_SIGNATURE=False`（当前默认，**发版前必须打开**） | 关闭时仅校验格式不验签，启动日志会明确告警 |

## 1. 这是什么

一套**离线非对称签名激活**方案：

- 卖家/管理员在**注册码后台**生成注册码（RSA 签名）
- 用户在客户端粘贴注册码
- 客户端用**内置公钥**本地验签，通过后写入加密授权文件

**机制上保证了：**

| 性质 | 说明 |
|---|---|
| 客户端**不需要联网** | 验签是纯本地计算，用户在无网环境也能激活 |
| 注册码**无法伪造** | 签名需要私钥，而私钥只在服务端，客户端只有公钥 |
| 注册码**绑定机器** | 载荷里含机器码，换机器验签报 `1003` |
| 注册码**绑定软件** | 载荷里含软件编码，跨软件使用报 `1005` |
| 授权文件**不可搬运** | 加密密钥由本机机器码派生，拷到别的机器解密失败（`1006`） |

**它做不到：**

| 限制 | 原因 | 缓解 |
|---|---|---|
| 无法远程撤销已发出的码 | 离线模式收不到回收指令 | 只能靠有效期到期自然失效 |
| 用户改本机系统时间可绕过有效期 | 时间由客户端本地读取 | 离线方案固有；如需强管控要上联网校验 |
| 换硬件（主板/网卡）可能导致机器码变化 | 指纹取自硬件 | 用户协议写明；后台支持重新出码 |
| **客户端本地的公钥可被替换** | 公钥是明文放在安装目录里的，攻击者可以改包或运行时替换 | 见下；唯一有效缓解是**给安装包做代码签名** |

> **关于最后一条，说清楚边界。** 这不是本方案的实现缺陷，而是**所有离线授权方案的固有性质** —— 校验逻辑跑在攻击者的机器上，他能改代码就能改公钥。已实测：用攻击者自己生成的密钥对按同样的协议伪造一张永久码，用官方公钥验签返回 `1002 签名校验失败`；而把公钥换成攻击者自己的，同一张伪造码**验签通过**。
>
> 实际威胁等级：攻击者必须具备**逆向/改包能力**，普通买家做不到，所以用来防「随便找个人编个码」完全够用。**如果装了窃取代码/破解版的风险**，必须给安装包做 **Windows 代码签名（Authenticode）** —— 用户系统会校验签名，改过包的会直接提示「来源不明/签名无效」。**这是本方案里唯一能提升到「防破解」级别的措施，接入时建议一并规划。**
>
> 反过来说，如果你的对手会改包，那么**任何本地校验都拦不住**（他可以直接跳过校验逻辑），此时只能上联网校验 —— 那已经超出本方案范围。

## 2. 接入前要拿到的三样东西

| # | 东西 | 从哪拿 | 说明 |
|---|---|---|---|
| 1 | **`APP_CODE`（软件编码）** | 向管理员提供「软件名称 + 英文编码」→ 管理员在后台「软件管理」里创建 | 形如 `LANYAZI_GRADE`，**大写字母/数字/下划线，2~32 位**。创建后**不可修改** |
| 2 | **`keys/public.pem`** | 向管理员索取（就是服务端 `keys/` 目录下那把公钥） | 整个方案里客户端**只需要这一个密钥文件** |
| 3 | **一个测试注册码** | 管理员在后台为你的 `APP_CODE` 生成，机器码填 §6-T1 里客户端显示的那个 | 用于验证接入成功 |

### 🔑 关于公钥：**必须打进安装包，这一步不能省**

> **问得最多的一个问题：「这个不需要把公钥打包进去吗？」**
> **答案是必须打包，而且不打包 100% 跑不起来。** 下面是完整解释。

**为什么必须打包。** 本方案是**离线**验签 —— 客户端不联网、不访问任何服务端。验签唯一需要的输入就是公钥，所以公钥如果不随程序分发，客户端手里就什么都没有，**一个注册码也验不了**。这不是「可选优化」，是方案能成立的前提。

**为什么公钥不怕泄露、可以随便分发。** 非对称密钥的安全性建立在**单向性**上：

| | 服务端持有 | 客户端持有 | 能否互相推导 |
|---|---|---|---|
| 私钥 `private.pem` | ✅ **只有服务端有** | ❌ **绝对不能有** | — |
| 公钥 `public.pem` | ✅ | ✅ **必须内置** | 从公钥**推不出**私钥（RSA-2048 目前算力下不可行） |

所以把公钥发给别人、放进安装包、让人随便看，**都不损失任何安全性**。真正要守的只有一条：**私钥永不离开服务端**（本仓库有自动用例 `test_k09c_client_never_touches_private_key` 扫描 `client/` 目录，一旦出现 `private` 字样就失败）。

**⚠️ 全系统共用同一把公钥。** 服务端只有一对密钥（`keys/private.pem` + `keys/public.pem`），**所有软件共用**。这意味着：

- 无论你接入的是第 1 个还是第 20 个软件，拿到的 `public.pem` **都是同一个文件、字节完全相同** —— 不用每接一个软件就重新申请一次
- 好处是管理简单；代价是**私钥一旦泄露，所有软件的注册码同时失效**，只能重新生成密钥对并让全部已激活用户重新激活
- ⚠️ 因此**不要**让公钥随每个项目各存一份「自己改过的版本」。如果你想改公钥内容，只会让该软件所有注册码验签失败（`1002`）

**落地三步（缺一步都会在客户那里炸）：**

```bash
# ① 放：把管理员给的 public.pem 放进资源目录
#    路径必须是 <项目>/license/resources/keys/public.pem
#    （config.resource_path() 的开发态基准目录就是 license/resources/）

# ② 带：打包命令 / spec 里必须包含它，目标目录固定为 keys/
pyinstaller --add-data "license/resources/keys/public.pem;keys" ...

# ③ 验：打包后逐条检查（第 3 条是最容易被忽略的安全断言）
ls dist/<你的软件名>/keys/public.pem     # 必须存在
ls dist/<你的软件名>/keys/private*       # 必须"没有输出"——有则说明打包脚本把私钥也带进来了
```

**打包后公钥的路径由 `sys._MEIPASS` 解析**（不是相对 exe 的目录），`config.resource_path()` 已经处理好了 —— 已实测：模拟打包态时解析到 `<_MEIPASS>/keys/public.pem`，开发态解析到 `<项目>/license/resources/keys/public.pem`；文件缺失时抛 `RuntimeError: 内置公钥缺失：<路径>；请重新安装客户端`。

> ⚠️ **这个坑在开发机上永远复现不了** —— 开发态的 `resources/keys/public.pem` 一直在，只有打包漏带才会报错。所以**每次打包都必须跑上面第 ③ 步**，别等发到客户那儿才发现。

### ⚠️ 关于机器码：**强烈建议复用本指南的采集算法**

机器码由**客户端自己采集**，服务端不参与计算（只做归一化比对）。所以理论上你可以自己定义算法。

但**强烈建议照抄本指南的算法**（§3.4），因为：

- 同一台机器在不同软件里会得到**完全相同**的机器码
- 代理/客服只需向买家索要**一次**机器码，就能为多个软件出码
- 否则每换一个软件就要重新教买家"怎么找机器码"

**如果你已经有一套机器码算法且不想改**：可以，但**必须在客户端采集与后台出码时为同一个软件用同一套算法**，否则会一直报 `1003`。这种情况需要单独跟管理员说明。

## 3. 协议规范（字节级，实现必须严格一致）

### 3.1 注册码结构

```
LG1 . <payload_b64> . <signature_b64>
 │         │                │
 │         │                └─ RSA 签名，base64url 后约 342 字符
 │         └─ payload JSON base64url 后约 270~400 字符
 └─ 前缀：LG + 协议版本号 1
```

- 分隔符是 ASCII 句点 `.`，**恰好 2 个**
- 整码长度约 **530~700** 字符
- 用户粘贴时可能带上换行/空格/全角空格 —— **校验前先去掉所有空白字符**

### 3.2 payload 定义

payload 是一个 JSON 对象，**服务端生成时按以下规则序列化**（客户端只需能解析，不需要自己生成）：

| 键 | 含义 | 类型 | 说明 |
|---|---|---|---|
| `v` | 协议版本 | int | 恒为 `1` |
| `c` | 软件编码 | str | 与你的 `APP_CODE` 比对 |
| `m` | 机器码 | str | 32 位大写 hex，**无分隔符** |
| `e` | 绑定邮箱 | str | 可为空串 `""` |
| `p` | 绑定手机号 | str | 可为空串 `""` |
| `x` | 到期时间 | int | **UTC 秒级时间戳**；**`0` 表示永久** |
| `s` | 随机盐 | str | 16 字节随机数的 hex（不参与校验，留档用） |
| `i` | 注册码 ID | int | 服务端记录 ID（不参与校验，报错时可提供给客服） |

> 八个键**全部一定存在**，值为空时是 `""` / `0`，不会缺键。

### 3.3 签名算法

| 项 | 取值 |
|---|---|
| 算法 | RSA-2048 |
| 填充 | **PKCS#1 v1.5**（不是 PSS） |
| 摘要 | SHA-256 |
| **签名对象** | **`payload_b64` 这一段字符串的 ASCII 字节** |
| 编码 | base64url，**去除 `=` 填充** |

> ### 🔴 最容易写错的一点
>
> 签名对象是**「base64 编码后的那串字符」**，**不是**：
> - ❌ 解码后的 JSON 字节
> - ❌ 原始 JSON 文本的字节
> - ❌ 整个注册码
>
> 这样设计是为了消除两端 JSON 序列化差异（键顺序、空格、Unicode 转义）导致的验签失败。
> **实现时直接对 `payload_b64` 这个字符串取 ASCII 字节去验签即可，不要做任何解码。**

### 3.4 机器码算法

#### 采集（按固定顺序拼接）

| 序 | 来源 | Windows 取法 |
|---|---|---|
| 1 | 主板/BIOS UUID | `wmic csproduct get uuid` |
| 2 | CPU ID | `wmic cpu get ProcessorId` |
| 3 | 系统盘序列号 | `wmic diskdrive get SerialNumber`（取第一条） |
| 4 | 主网卡 MAC | `uuid.getnode()` 格式化为 12 位大写 hex |

**任一项取不到就填空串**，位置保留（用 `|` 分隔）。
**顺序不能改**——顺序一变，同一台机器的机器码就变了，已发出的注册码会集体失效。

> **Windows 11 24H2 起系统不再自带 `wmic`**。必须准备 PowerShell/CIM 兜底通道，
> 否则机器码会退化成「只有 MAC」，同一台机器在系统升级前后对不上。

#### 计算

```
raw        = 上述四项用 "|" 连接              （固定顺序，缺失位为空串）
digest     = SHA-256(raw 的 UTF-8 字节).hexdigest()
machine_id = digest 的前 32 个字符，转大写      （32 位 hex）
```

#### 两种形式

| 形式 | 用途 | 示例 |
|---|---|---|
| **标准形式** | 比对、签名、存授权文件 | `A1B2C3D4E5F60718293A4B5C6D7E8F90` |
| **显示形式** | 界面展示、发给卖家 | `A1B2-C3D4-E5F6-0718-293A-4B5C-6D7E-8F90` |

#### 归一化（比对前必须做）

```
只保留 [0-9A-Fa-f] 字符，然后转大写
```

服务端入库时已归一化，客户端比对前也要归一化，否则用户粘贴带 `-` 的形式会误报 `1003`。

> ⚠️ 注意这个规则的含义：`"GGGG…G"`（32 个 G）归一化后是**空串**，不是"格式错误"。

### 3.5 错误码表

| 码 | 含义 | 用户看到的文案（建议） |
|---|---|---|
| `1000` | 未知错误 | 未知错误，请截图后联系卖家 |
| `1001` | 注册码格式错误 | 注册码格式不正确，请确认完整复制（注意不要漏掉或多加字符） |
| `1002` | 签名验证失败 | 注册码校验失败，请联系卖家确认 |
| `1003` | 机器码不匹配 | 该注册码不适用于本机，请把本机机器码发给卖家重新出码 |
| `1004` | 注册码已过期 | 注册码已过期，请续费 |
| `1005` | 软件不匹配 | 该注册码不适用于当前软件 |
| `1006` | 授权文件损坏 | 本地授权文件已损坏，请重新激活 |
| `1007` | 授权文件不存在 | 尚未激活 |
| `1008` | 注册码版本不支持 | 注册码版本过新，请升级软件 |

**规则**：界面只显示文案，**不要把错误码或异常堆栈给用户看**（除了让用户转告客服的那几个）。

### 3.6 授权文件格式

**位置**

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\<产品名>\license.dat` |
| 其他 | `~/.config/<产品名>/license.dat` |

**内容（加密前）**

```json
{ "code": "LG1.eyJ2IjoxLC...", "payload": { "v":1, "c":"...", "m":"...", "x":1820000000, ... },
  "activated_at": "2026-01-02T10:00:00Z", "app_version": "1.0.0" }
```

**加密**

| 项 | 值 |
|---|---|
| 算法 | AES-256-GCM |
| 密钥派生 | `PBKDF2-HMAC-SHA256(password=机器码标准形式, salt, iterations=200000, dklen=32)` |
| 文件结构 | `salt(16) ‖ nonce(12) ‖ ciphertext ‖ tag(16)` |
| AAD | 无（空） |

> 密钥由机器码派生 = 把授权文件绑死在本机。拷到别的机器 → 派生结果不同 → 解密失败 → `1006`。

### 3.7 校验顺序（**不可颠倒**）

```
1. 清洗输入（去掉所有空白）
2. 分段与版本检查                 → 1001 / 1008
3. RSA 验签                       → 1002        ← 必须在任何内容比对之前
4. 解析 payload（此时才可信）
5. 软件编码比对                   → 1005
6. 机器码比对（双方先归一化）      → 1003
7. 有效期比对（x = 0 视为永久）    → 1004
8. 全部通过 → 写加密授权文件
```

> **第 3 步必须在第 5~7 步之前。** 顺序反过来等于把未经验签的数据当可信数据使用 ——
> 攻击者可以随意构造一个 payload 让程序读到「永久有效」。

```python
"""机器码采集、计算、归一化与格式化。

采集顺序固定为「主板 UUID → CPU ID → 系统盘序列号 → 主网卡 MAC」，
任一来源取不到就填空串——顺序一变，同一台机器的机器码就变了，
已发出的注册码会集体失效。

前三项优先走 wmic，整组不可用时改用 PowerShell/CIM（读同一组 WMI 属性）：
Windows 11 24H2 起系统已不带 wmic，只留一条通道会让机器码退化成「仅 MAC」。
"""

import hashlib
import logging
import re
import subprocess
import sys
import uuid
from typing import Final

from license.errors import ERR_UNKNOWN, BizError

logger = logging.getLogger(__name__)

MACHINE_ID_LENGTH: Final[int] = 32
GROUP_SIZE: Final[int] = 4
WMIC_TIMEOUT_SECONDS: Final[int] = 5

_STRIP_PATTERN: Final[re.Pattern[str]] = re.compile(r"[^0-9A-Fa-f]")
_STANDARD_PATTERN: Final[re.Pattern[str]] = re.compile(r"^[0-9A-F]{32}$")

#: 顺序即拼接顺序（顺序一变机器码就变）
_WMIC_QUERIES: Final[tuple[str, ...]] = (
    "csproduct get uuid",
    "cpu get ProcessorId",
    "diskdrive get SerialNumber",
)

#: wmic 缺失时的整组兜底：一次 PowerShell 调用取回同样三个 WMI 属性。
#: 逐项调用要起 3 次 PowerShell 进程（实测 4.4 秒），会顶到激活超时。
_CIM_BATCH_SCRIPT: Final[str] = (
    "$ErrorActionPreference='SilentlyContinue'; "
    "$c=Get-CimInstance Win32_ComputerSystemProduct; "
    "$p=Get-CimInstance Win32_Processor | Select-Object -First 1; "
    "$d=Get-CimInstance Win32_DiskDrive | Select-Object -First 1; "
    'Write-Output "$($c.UUID)|$($p.ProcessorId)|$($d.SerialNumber)"'
)

_cached_machine_id: str | None = None


def _run_wmic(query: str) -> str:
    """wmic 通道，失败或超时返回空串。

    CREATE_NO_WINDOW 不能省：打包成窗口程序后不加会闪一下黑色控制台。
    """
    if not sys.platform.startswith("win"):
        return ""
    try:
        output = subprocess.check_output(
            ["wmic", *query.split()],
            timeout=WMIC_TIMEOUT_SECONDS,
            creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0),
            stderr=subprocess.DEVNULL,
        )
    except (OSError, subprocess.SubprocessError) as exc:
        logger.debug("wmic 查询失败（%s）：%s", query, exc)
        return ""

    lines = [
        line.strip()
        for line in output.decode("utf-8", errors="ignore").splitlines()
        if line.strip()
    ]
    # 第一行是列标题，真正的结果从第二行开始
    return lines[1] if len(lines) > 1 else ""


def _run_powershell(script: str) -> str:
    """PowerShell / CIM 通道（Windows 11 24H2 起 wmic 已被移除）。"""
    if not sys.platform.startswith("win"):
        return ""
    try:
        output = subprocess.check_output(
            ["powershell", "-NoProfile", "-NonInteractive", "-Command", script],
            timeout=WMIC_TIMEOUT_SECONDS,
            creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0),
            stderr=subprocess.DEVNULL,
        )
    except (OSError, subprocess.SubprocessError) as exc:
        logger.debug("PowerShell 查询失败：%s", exc)
        return ""

    lines = [
        line.strip()
        for line in output.decode("utf-8", errors="ignore").splitlines()
        if line.strip()
    ]
    return lines[0] if lines else ""


def _collect_via_cim() -> tuple[str, str, str]:
    """一次 PowerShell 调用取回三项硬件信息。"""
    output = _run_powershell(_CIM_BATCH_SCRIPT)
    if not output:
        return ("", "", "")
    parts = output.split("|")
    if len(parts) != len(_WMIC_QUERIES):
        logger.warning("CIM 批量输出格式异常，按采集失败处理")
        return ("", "", "")
    return (parts[0].strip(), parts[1].strip(), parts[2].strip())


def _query_sources() -> list[str]:
    """取回前三项硬件信息：优先整组 wmic，不可用则整组走 CIM。

    按「整组切换」而不是逐项降级——混用两条通道可能出现细微格式差异，
    那会让机器码在系统升级前后对不上。
    """
    values = [_run_wmic(query) for query in _WMIC_QUERIES]
    if all(values):
        return values
    logger.debug("wmic 通道不可用，改用 PowerShell/CIM")
    return list(_collect_via_cim())


def _primary_mac() -> str:
    """主网卡 MAC（uuid.getnode() 兜底，基本不会失败）。"""
    return f"{uuid.getnode():012X}"


def collect_raw_fingerprint() -> str:
    """采集硬件指纹原始串（``|`` 分隔，缺失位为空串）。

    Raises:
        BizError: 四项全部采集失败（1000）——真机上不会发生，但必须有兜底。
    """
    parts = [*_query_sources(), _primary_mac()]
    if not any(parts):
        raise BizError(ERR_UNKNOWN, "无法采集本机硬件信息")
    return "|".join(parts)


def compute_machine_id(raw: str) -> str:
    """原始串 → 标准形式机器码（SHA-256 前 32 位大写 hex）。"""
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()[:MACHINE_ID_LENGTH].upper()


def normalize_machine_id(raw: str) -> str:
    """任意形式 → 标准形式（去分隔符 / 空白 / 大小写）。"""
    return _STRIP_PATTERN.sub("", raw or "").upper()


def format_machine_id(machine_id: str) -> str:
    """标准形式 → 显示形式（每 4 位加 ``-``）。"""
    if len(machine_id) != MACHINE_ID_LENGTH:
        return machine_id
    return "-".join(
        machine_id[index : index + GROUP_SIZE]
        for index in range(0, len(machine_id), GROUP_SIZE)
    )


def is_standard_machine_id(machine_id: str) -> bool:
    """判断是否为标准形式（32 位大写 hex）。"""
    return bool(_STANDARD_PATTERN.fullmatch(machine_id))


def get_machine_id() -> str:
    """获取本机机器码（标准形式），带进程内缓存。

    采集要调三次 wmic（数百毫秒），一次激活流程会多次用到，故做缓存。

    Raises:
        BizError: 硬件信息采集全部失败（1000）。
    """
    global _cached_machine_id
    if _cached_machine_id is None:
        _cached_machine_id = compute_machine_id(collect_raw_fingerprint())
    return _cached_machine_id


def reset_machine_id_cache() -> None:
    """清空机器码缓存（换机测试用）。"""
    global _cached_machine_id
    _cached_machine_id = None
```

```python
"""注册码验签模块。**只使用公钥，绝不接触私钥**。

校验顺序不可颠倒：先验签，再比对内容——顺序反过来等于把未经验签的数据
当可信数据使用。
"""

import base64
import json
import logging
import time
from dataclasses import dataclass, field
from typing import Any

from cryptography.exceptions import InvalidSignature
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding

from license.errors import (
    ERR_APP_MISMATCH,
    ERR_LICENSE_EXPIRED,
    ERR_LICENSE_FORMAT,
    ERR_LICENSE_VERSION,
    ERR_MACHINE_MISMATCH,
    ERR_SIGNATURE_INVALID,
)
from license.machine_id import normalize_machine_id

logger = logging.getLogger(__name__)

PROTOCOL_VERSION: int = 1
SUPPORTED_PREFIXES: frozenset[str] = frozenset({"LG1"})
SEGMENT_COUNT: int = 3


@dataclass
class VerifyResult:
    """验签结果。"""

    ok: bool
    code: int = 0
    message: str = ""
    payload: dict[str, Any] = field(default_factory=dict)


def _b64url_decode(text: str) -> bytes:
    """解码 base64url，自动补齐 ``=`` 填充。"""
    return base64.urlsafe_b64decode(text + "=" * (-len(text) % 4))


def verify_license(
    code_text: str,
    public_key_pem: bytes,
    expected_app_code: str,
    local_machine_id: str,
    now_ts: int | None = None,
) -> VerifyResult:
    """离线验签注册码。

    校验顺序（不可颠倒）：格式/版本 → 验签 → 软件编码 → 机器码 → 有效期。

    Args:
        code_text: 用户粘贴的注册码原文（可含空白与换行）。
        public_key_pem: 内置公钥的 PEM 字节。
        expected_app_code: 本软件自己的软件编码。
        local_machine_id: 本机机器码（任意形式，内部归一化）。
        now_ts: 当前 UTC 时间戳，便于测试注入；默认取系统时间。

    Returns:
        VerifyResult；``ok=True`` 时 ``payload`` 为解析出的载荷。
    """
    now_ts = int(time.time()) if now_ts is None else now_ts

    # 1) 清洗与格式检查：一次性去掉所有空白（含换行、制表符、全角空格）
    cleaned = "".join(code_text.split())
    parts = cleaned.split(".")
    if len(parts) != SEGMENT_COUNT or parts[0] not in SUPPORTED_PREFIXES:
        if len(parts) == SEGMENT_COUNT and parts[0].startswith("LG"):
            return VerifyResult(False, ERR_LICENSE_VERSION, "注册码版本不支持")
        return VerifyResult(False, ERR_LICENSE_FORMAT, "注册码格式错误")
    _, payload_b64, signature_b64 = parts

    # 2) 验签（早于任何内容判断）
    try:
        public_key = serialization.load_pem_public_key(public_key_pem)
        public_key.verify(
            _b64url_decode(signature_b64),
            payload_b64.encode("ascii"),
            padding.PKCS1v15(),
            hashes.SHA256(),
        )
    except InvalidSignature:
        return VerifyResult(False, ERR_SIGNATURE_INVALID, "签名验证失败")
    except Exception:
        # base64 非法、公钥不可加载、payload 段含非 ASCII 字符等一律归为格式错误
        return VerifyResult(False, ERR_LICENSE_FORMAT, "注册码格式错误")

    # 3) 解析 payload（此时已可信）
    try:
        payload = json.loads(_b64url_decode(payload_b64).decode("utf-8"))
    except Exception:
        return VerifyResult(False, ERR_LICENSE_FORMAT, "注册码内容损坏")
    if not isinstance(payload, dict):
        return VerifyResult(False, ERR_LICENSE_FORMAT, "注册码内容损坏")

    if int(payload.get("v", 0)) != PROTOCOL_VERSION:
        return VerifyResult(False, ERR_LICENSE_VERSION, "注册码版本不支持")

    # 4) 软件编码
    if payload.get("c") != expected_app_code:
        return VerifyResult(False, ERR_APP_MISMATCH, "该注册码不适用于当前软件")

    # 5) 机器码
    if normalize_machine_id(str(payload.get("m", ""))) != normalize_machine_id(local_machine_id):
        return VerifyResult(False, ERR_MACHINE_MISMATCH, "该注册码不适用于本机")

    # 6) 有效期（x = 0 表示永久）
    expire_ts = int(payload.get("x", 0))
    if expire_ts and now_ts > expire_ts:
        return VerifyResult(False, ERR_LICENSE_EXPIRED, "注册码已过期")

    return VerifyResult(True, 0, "激活成功", payload)
```

```python
"""授权文件的加密读写。

文件结构：``salt(16) || nonce(12) || ciphertext || tag(16)``
密钥：``PBKDF2-HMAC-SHA256(机器码标准形式, salt, 200_000, dklen=32)``

密钥由机器码派生，等于把授权文件绑死在本机：拷到别的机器上派生结果不同，
解密必然失败（1006）——这是离线方案的换机防护。
"""

import json
import logging
import os
from pathlib import Path
from typing import Any

from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from cryptography.hazmat.primitives.kdf.pbkdf2 import PBKDF2HMAC

from license.errors import ERR_LICENSE_FILE_CORRUPT, BizError

logger = logging.getLogger(__name__)

SALT_LENGTH: int = 16
NONCE_LENGTH: int = 12
TAG_LENGTH: int = 16
KEY_LENGTH: int = 32
KDF_ITERATIONS: int = 200_000
DEFAULT_FILE_NAME: str = "license.dat"


def _derive_key(machine_id: str, salt: bytes) -> bytes:
    """用机器码与盐派生 AES-256 密钥。"""
    kdf = PBKDF2HMAC(
        algorithm=hashes.SHA256(),
        length=KEY_LENGTH,
        salt=salt,
        iterations=KDF_ITERATIONS,
    )
    return kdf.derive(machine_id.encode("utf-8"))


def license_file_path(app_name: str, file_name: str = DEFAULT_FILE_NAME) -> Path:
    """返回授权文件路径；目录不存在时创建。

    Windows 用 ``%APPDATA%\\<产品名>``，其他平台退回 ``~/.config/<产品名>``。
    """
    appdata = os.environ.get("APPDATA")
    directory = Path(appdata) / app_name if appdata else Path.home() / ".config" / app_name
    directory.mkdir(parents=True, exist_ok=True)
    return directory / file_name


def save_license_file(path: Path, data: dict[str, Any], machine_id: str) -> None:
    """把授权信息加密写入本地文件。

    AESGCM.encrypt() 返回的正是 ``ciphertext || tag``，与文件结构要求一致。
    """
    salt = os.urandom(SALT_LENGTH)
    nonce = os.urandom(NONCE_LENGTH)
    sealed = AESGCM(_derive_key(machine_id, salt)).encrypt(
        nonce,
        json.dumps(data, ensure_ascii=False).encode("utf-8"),
        None,
    )
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_bytes(salt + nonce + sealed)
    logger.info("授权文件已写入：%s", path)


def load_license_file(path: Path, machine_id: str) -> dict[str, Any] | None:
    """解密读取授权文件。

    Returns:
        授权字典；文件不存在时返回 None。

    Raises:
        BizError: 文件长度异常、解密失败或内容不是 JSON 对象（1006）。
            换机、改文件、AES 标签校验不过都会落到这里。
    """
    if not path.exists():
        return None

    blob = path.read_bytes()
    if len(blob) <= SALT_LENGTH + NONCE_LENGTH + TAG_LENGTH:
        logger.warning("授权文件长度异常：%s 字节", len(blob))
        raise BizError(ERR_LICENSE_FILE_CORRUPT)

    salt = blob[:SALT_LENGTH]
    nonce = blob[SALT_LENGTH : SALT_LENGTH + NONCE_LENGTH]
    sealed = blob[SALT_LENGTH + NONCE_LENGTH :]
    try:
        plain = AESGCM(_derive_key(machine_id, salt)).decrypt(nonce, sealed, None)
        data = json.loads(plain.decode("utf-8"))
    except Exception as exc:
        logger.warning("授权文件解密失败：%s", type(exc).__name__)
        raise BizError(ERR_LICENSE_FILE_CORRUPT) from exc

    if not isinstance(data, dict):
        raise BizError(ERR_LICENSE_FILE_CORRUPT)
    return data


def clear_license_file(path: Path) -> None:
    """删除授权文件（用于「重新激活」）；文件不存在时静默返回。"""
    path.unlink(missing_ok=True)
    logger.info("授权文件已清除：%s", path)
```

#### 三条硬要求

**① UI 主线程绝不阻塞**

机器码采集要调 3 次 `wmic`（数百毫秒）、授权文件解密要做 **20 万次 PBKDF2**（约 100~300ms）。
这些全部会卡住界面导致白屏。必须放子线程：

```python
class ActivateWorker(QThread):
    succeeded = Signal(dict)
    failed = Signal(int, str)

    def run(self) -> None:
        try:
            machine_id = machine_id_module.get_machine_id()
            result = verifier.verify_license(
                self.code_text, config.public_key_pem(), config.APP_CODE, machine_id
            )
            if not result.ok:
                self.failed.emit(result.code, result.message)
                return
            store.save_license_file(
                store.license_file_path(config.APP_NAME, config.LICENSE_FILE_NAME),
                {
                    "code": self.code_text,
                    "payload": result.payload,
                    "activated_at": datetime.now(timezone.utc).isoformat(),
                    "app_version": config.APP_VERSION,
                },
                machine_id,
            )
            self.succeeded.emit(result.payload)
        except Exception:
            logger.exception("激活失败")
            self.failed.emit(ERR_UNKNOWN, message_for(ERR_UNKNOWN))
```

- 子线程**只通过信号回传**，**禁止直接操作控件**
- `try/except` 必须有 —— 否则异常会让 `failed` 信号发不出来，按钮永远转圈
- 点击后立即禁用按钮 + 显示「激活中…」，防止重复点击

**② 每次启动都要重新验签**

不能只检查「授权文件存在」就认为已激活 —— 用户复制一份改过的文件就能绕过。

```python
def check_activated() -> tuple[bool, str, dict | None]:
    """启动时调用。返回 (是否已激活, 提示文案, payload)。"""
    path = store.license_file_path(config.APP_NAME, config.LICENSE_FILE_NAME)
    machine_id = machine_id_module.get_machine_id()          # 也放子线程
    try:
        data = store.load_license_file(path, machine_id)
    except BizError as exc:                                   # 1006
        return False, exc.message, None
    if data is None:                                          # 1007
        return False, message_for(ERR_LICENSE_FILE_MISSING), None

    result = verifier.verify_license(
        str(data.get("code", "")), config.public_key_pem(), config.APP_CODE, machine_id
    )
    if not result.ok:
        return False, result.message, None
    return True, "已激活", result.payload
```


用户是从微信/淘宝粘贴过来的，带换行很正常。**不要因为里面有换行就报错**。

### 4.5 打包（PyInstaller）

```bash
pyinstaller --noconfirm --clean --onedir --windowed \
    --name "你的软件名" \
    --add-data "license/resources/keys/public.pem;keys" \
    main.py
```

- **必须用 `--onedir`**：`--onefile` 的自解压行为极易被杀软误报
- **`--add-data` 的目标目录必须是 `keys`**（源码里 `PUBLIC_KEY_RESOURCE = "keys/public.pem"`）。Windows 下源与目标之间用 `;` 分隔，Linux/macOS 用 `:` —— 写错会静默地把文件放错位置

- 开发态与打包态的资源路径由 `config.resource_path()` 统一处理（`sys._MEIPASS`），落在 `keys/` 下的文件名不要改

> 🔑 **公钥的来源、共性与安全边界见 §2 的「关于公钥」小节** —— 三个高频问题（要不要打包、为什么不怕泄露、是否每个软件各一把）都在那里。

## 5. 路径 B：非 Python 项目

### 5.1 五个最容易写错的地方

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | **签名对象搞错** | 对 `payload_b64` **字符串的 ASCII 字节**验签。不是解码后的 JSON，也不是原始 JSON，更不是整码 |
| 2 | **base64url 与 base64 混用** | 注册码用的是 **base64url**（`-` `_`），且**没有 `=` 填充**。解码前要先把 `-→+`、`_→/` 并补 `=` |
| 3 | **机器码没归一化** | 比对前双方都要「只保留 `[0-9A-Fa-f]` 并转大写」，否则带 `-` 的显示形式会误报 `1003` |
| 4 | **时间戳当成本地时间** | `x` 是 **UTC 秒级时间戳**（不是毫秒）。`x == 0` 表示**永久**，不要当成 1970 年 |
| 5 | **AES-GCM 用了 AAD** | 授权文件的 AAD 是**空**。多传了 AAD 会导致解密永远失败 |

### 5.2 C# / .NET

```csharp
using System.Linq;
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;

public static class LicenseVerifier
{
    public const int ErrFormat = 1001, ErrBadSignature = 1002, ErrMachine = 1003,
                     ErrExpired = 1004, ErrAppMismatch = 1005, ErrVersion = 1008;

    /// <summary>离线验签。返回 0 表示通过，否则为错误码。</summary>
    public static int Verify(string codeText, string publicKeyPem, string appCode,
                             string localMachineId, out JsonElement payload)
    {
        payload = default;
        var cleaned = new string(codeText.Where(c => !char.IsWhiteSpace(c)).ToArray());
        var parts = cleaned.Split('.');
        if (parts.Length != 3 || parts[0] != "LG1")
            return parts.Length == 3 && parts[0].StartsWith("LG") ? ErrVersion : ErrFormat;

        string payloadB64 = parts[1], signatureB64 = parts[2];

        // 关键：对 payloadB64 的 ASCII 字节验签
        using var rsa = RSA.Create();
        rsa.ImportFromPem(publicKeyPem);
        bool ok = rsa.VerifyData(
            Encoding.ASCII.GetBytes(payloadB64),
            B64UrlDecode(signatureB64),
            HashAlgorithmName.SHA256,
            RSASignaturePadding.Pkcs1);      // 必须是 Pkcs1，不是 Pss
        if (!ok) return ErrBadSignature;

        using var doc = JsonDocument.Parse(Encoding.UTF8.GetString(B64UrlDecode(payloadB64)));
        payload = doc.RootElement.Clone();
        if (payload.GetProperty("v").GetInt32() != 1) return ErrVersion;
        if (payload.GetProperty("c").GetString() != appCode) return ErrAppMismatch;
        if (Normalize(payload.GetProperty("m").GetString()) != Normalize(localMachineId))
            return ErrMachine;

        long expire = payload.GetProperty("x").GetInt64();
        if (expire != 0 &&
            DateTimeOffset.UtcNow.ToUnixTimeSeconds() > expire) return ErrExpired;
        return 0;
    }

    public static byte[] B64UrlDecode(string s)
    {
        s = s.Replace('-', '+').Replace('_', '/');
        switch (s.Length % 4) { case 2: s += "=="; break; case 3: s += "="; break; }
        return Convert.FromBase64String(s);
    }

    public static string Normalize(string? s) =>
        new string((s ?? "").Where(Uri.IsHexDigit).ToArray()).ToUpperInvariant();
}
```

### 5.3 Node.js / Electron

```js
const crypto = require('crypto');

function b64urlToBuf(s) {
  s = s.replace(/-/g, '+').replace(/_/g, '/');
  while (s.length % 4) s += '=';
  return Buffer.from(s, 'base64');
}

/** 返回 0 表示通过，否则错误码 */
function verifyLicense(codeText, publicKeyPem, appCode, localMachineId, nowTs) {
  const cleaned = codeText.replace(/\s+/g, '');
  const parts = cleaned.split('.');
  if (parts.length !== 3 || parts[0] !== 'LG1') {
    return (parts.length === 3 && parts[0].startsWith('LG')) ? 1008 : 1001;
  }
  const [, payloadB64, signatureB64] = parts;

  const ok = crypto.verify(
    'sha256',
    Buffer.from(payloadB64, 'ascii'),                    // ← 关键：ASCII 字节
    { key: publicKeyPem, padding: crypto.constants.RSA_PKCS1_PADDING },
    b64urlToBuf(signatureB64));
  if (!ok) return 1002;

  const payload = JSON.parse(b64urlToBuf(payloadB64).toString('utf8'));
  if (payload.v !== 1) return 1008;
  if (payload.c !== appCode) return 1005;
  if (normalize(payload.m) !== normalize(localMachineId)) return 1003;

  const now = nowTs ?? Math.floor(Date.now() / 1000);
  if (payload.x !== 0 && now > payload.x) return 1004;
  return 0;
}

const normalize = (s) => (s || '').replace(/[^0-9A-Fa-f]/g, '').toUpperCase();
```

```js
function deriveKey(machineId, salt) {
  return crypto.pbkdf2Sync(machineId, salt, 200000, 32, 'sha256');  // 迭代次数必须一致
}
function saveLicense(path, data, machineId) {
  const salt = crypto.randomBytes(16), nonce = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv('aes-256-gcm', deriveKey(machineId, salt), nonce);
  const ct = Buffer.concat([cipher.update(JSON.stringify(data), 'utf8'), cipher.final()]);
  fs.writeFileSync(path, Buffer.concat([salt, nonce, ct, cipher.getAuthTag()]));
}
```

```cpp
// 关键：对 payloadB64 的 ASCII 字节做 EVP_DigestVerify，填充用 RSA_PKCS1_PADDING
QByteArray payloadB64Bytes = payloadB64.toUtf8();
QByteArray sigBytes = QByteArray::fromBase64(
    signatureB64.toUtf8(),
    QByteArray::Base64UrlEncoding | QByteArray::OmitTrailingEquals);

EVP_PKEY* pkey = PEM_read_bio_PUBKEY(bio, nullptr, nullptr, nullptr);
EVP_MD_CTX* ctx = EVP_MD_CTX_new();
EVP_DigestVerifyInit(ctx, nullptr, EVP_sha256(), nullptr, pkey);
EVP_DigestVerifyUpdate(ctx, payloadB64Bytes.constData(), payloadB64Bytes.size());
int rc = EVP_DigestVerifyFinal(ctx, reinterpret_cast<const unsigned char*>(sigBytes.constData()),
```

接入完成后逐条执行并记录真实结果。**没跑完这 8 条不算接入成功。**

| # | 用例 | 期望 |
|---|---|---|
| T1 | 启动程序，读取界面显示的本机机器码 | 32 位 hex，显示形式为 8 组 4 位 |
| T2 | 把 T1 的机器码发给管理员换一个测试注册码，粘贴激活 | 激活成功，状态变为「已激活，有效期至 …」 |
| T3 | 关掉程序重启 | 直接显示已激活，**不需要重新输入注册码** |
| T4 | 手工把 `%APPDATA%\<产品名>\license.dat` 改掉 1 个字节，重启 | 报 `1006 本地授权文件已损坏，请重新激活`（**不能崩溃、不能白屏**） |
| T5 | 删除 `license.dat`，重启 | 显示未激活界面，可正常重新激活 |
| T6 | 用**别的机器**（或改 `MACHINE_A` 常量模拟）激活同一个码 | 报 `1003 该注册码不适用于本机` |
| T7 | 在代码里把 `now_ts` 注入成「有效期之后」的时间，调用 `verify_license` | 报 `1004 注册码已过期` |
| T8 | 把注册码中间随便改几个字符再激活 | 报 `1002 注册码校验失败`（**绝不能激活成功**） |

> （§4.2 的 `verifier.py` 已经留好了这个参数，**不要删**）。

## 8. 常见故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 一直报 `1002 签名校验失败` | ① 公钥文件不对（拿了别人的）② 签名对象写错了（对 JSON 而非 `payload_b64` 验签）③ 用了 PSS 填充 | 核对公钥；检查是否对 `payload_b64` 的 ASCII 字节验签；填充必须是 PKCS#1 v1.5 |
| 一直报 `1003 机器码不匹配` | ① 客户端的机器码算法与出码时用的不一致 ② 没做归一化 ③ 硬件变化 | 把客户端显示的标准形式（无 `-`）与后台记录里存的 `machine_id` 逐字符比对 |
| 一直报 `1005 软件不匹配` | `APP_CODE` 与后台不一致（大小写、下划线） | 与后台「软件管理」里的编码逐字符比对 |
| 报 `1001 格式错误` | 注册码复制不全（少了开头/结尾）、或中间混入了换行被当成段分隔 | 确认清洗逻辑用了 `"".join(text.split())`；确认整码长度约 530~700 |
| 报 `1008 版本不支持` | 拿到的是新版协议（`LG2`）的码，而客户端还是旧版 | 升级客户端 |
| 换机器后报 `1006 授权文件损坏` | 这是**预期行为**（授权文件与机器绑定） | 引导用户重新激活 |
| 打包后启动报「内置公钥缺失」 | `--add-data` 路径写错，或公钥没进包 | 检查 `dist/<名称>/keys/public.pem` 是否存在 |
| 激活时界面卡住几秒 | 机器码采集或 PBKDF2 跑在主线程 | 移到 `QThread`（见 §4.4 ①） |
